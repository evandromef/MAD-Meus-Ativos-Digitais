# MAD - Meus Ativos Digitais

MAD é uma aplicação web para gerenciamento de ativos digitais, permitindo o controle de ordens, proventos e eventos relacionados aos seus investimentos.

## Funcionalidades

- **Visualização de Ativos:** Consulte e gerencie todos os ativos cadastrados.
- **Gerenciamento de Ordens:** Cadastre, edite e exclua ordens de compra e venda.
- **Consulta de Proventos:** Veja os proventos recebidos, como dividendos e juros.
- **Acompanhamento de Eventos:** Liste eventos relevantes como desdobramentos, bonificações e assembleias.
